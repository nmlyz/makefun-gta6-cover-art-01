Vice Cover Maker — an offline web app that turns your photos and a caption into GTA 6-style multi-panel poster cover art: Vice City sunset and neon colour grades, bold Anton title lettering with a Pacifico script subtitle, five layouts, per-panel crop and position, halftone title block, grain and vignette, undo/redo, and PNG export at 1080×1080, 1080×1350 and 1920×1080. No photo ever leaves your machine; no Rockstar artwork, logo or font is used.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in desktop Chrome. Add photos with the file picker or by dropping them onto a panel, pick a layout and grade, edit the caption, and hit Export PNG.
